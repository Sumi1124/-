# Contributing to SourceDesk

Thanks for your interest! SourceDesk is an open-source, local-first AI research
notebook for macOS. All contributions — bug reports, feature ideas, docs, and
pull requests — are welcome.

## Ground rules

- **Local-first, always.** Notebook data must never leave the user's Mac unless
  the user explicitly triggers a cloud feature (AI provider call or web search).
- **Never auto-download model weights.** Ollama support detects models the user
  already installed; SourceDesk must never pull or download models on its own.
- **No new third-party dependencies without discussion.** Pure-Foundation and
  system frameworks are preferred (e.g. `ditto` over a zip library).
- Keep every piece of behavior testable without a full Xcode build whenever
  possible — put pure logic in `Utilities/` and cover it with unit tests.

## Project layout

```
SourceDesk/
├── App/            entry point + AppState
├── Models/         SwiftData models (SwiftData-free types live in Types.swift)
├── Services/       AI, Ingestion, RAG, Search, Storage, Study tools
├── Utilities/      pure Swift helpers (fully unit-tested, no SwiftData)
├── ViewModels/     ObservableObject view models
└── Views/          SwiftUI
SourceDeskTests/    XCTest unit tests
scripts/            project + icon generators
```

## Building and testing

1. Open `SourceDesk.xcodeproj` in Xcode 15+.
2. Run the **SourceDesk** scheme (⌘R) and tests (⌘U).

The project file is generated by `scripts/generate_project.py` — re-run it
after adding or removing files:

```bash
python3 scripts/generate_project.py
```

Code changes touch SwiftData types that can only be compiled inside Xcode, so
make sure the app builds before opening a PR.

## Code style

- Follow existing conventions: SwiftUI views are small `View` structs, logic
  lives in services/view models, pure algorithms in `Utilities/`.
- No comments unless they explain a non-obvious decision.
- Mark `@MainActor` for anything that touches SwiftData or the UI.

## Pull request checklist

- [ ] App builds in Xcode (Debug)
- [ ] `swiftc -typecheck` clean for pure `Utilities/` files
- [ ] Unit tests pass (⌘U), and you add a test for new pure logic
- [ ] Offline + Locale-Only Mode behavior verified for UI changes
- [ ] No new API keys, secrets, or data logged

## Reporting issues

Include: macOS version, Xcode version, SourceDesk commit, steps to reproduce,
and expected vs. actual behavior. For crashes, please attach the crash log.
